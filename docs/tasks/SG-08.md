## Objetivo

Implementar o cadastro de capacidades e o controle de carga horária pedagógica das unidades curriculares.

### 1. Unidade curricular

Adicione a carga horária prevista à entidade de UC da SG-07.

Preserve os contratos e os dados antigos. UCs existentes sem CH informada devem continuar válidas até seu planejamento ser completado.

Utilize representação numérica adequada para horas, evitando perda de precisão.

### 2. Capacidade

Crie a estrutura mínima necessária para representar:

- Unidade curricular.
- Descrição ou nome da capacidade.
- Conteúdos relacionados.
- Carga horária necessária.
- Ordem de apresentação.

Configure os relacionamentos e índices necessários, mantendo as convenções utilizadas na SG-07.

### 3. Regras de negócio

Implemente cálculos para:

- Somar as cargas horárias das capacidades.
- Comparar a soma com a CH prevista da UC.
- Informar OK, horas faltantes ou excedentes.
- Identificar UC ainda sem CH definida.
- Calcular encontros necessários usando `Ceiling(CH / horasPorTurno)`.

A duração do turno deve ser recebida como parâmetro. Não usar valores fixos.

Não confunda a carga horária pedagógica com a ocupação física de ambientes.

Não bloqueie o cadastro de capacidades somente porque a carga horária total ainda não fecha. Essa situação deverá ser apresentada no resumo.

### 4. Endpoints

Implemente endpoints REST de cadastro, consulta e atualização de capacidades, além de uma consulta ao resumo de CH da UC.

Siga os padrões existentes da SG-07, com DTOs, autorização administrativa para escrita e autenticação para leitura.

Não implemente exclusão física.

### 5. Migration

A SG-07 já possui a migration `SG07PedagogicalCatalog`.

Preserve-a, juntamente com `InitialCreate`.

Gere uma nova migration `SG08CapabilitiesWorkload`, caso as ferramentas oficiais estejam disponíveis.

Não edite migrations anteriores nem o snapshot manualmente.

Não aplique alterações em banco de produção.

### 6. Testes

Crie testes unitários para os cálculos, validações e regras novas.

Execute `dotnet build`, `dotnet test` e a verificação de alterações pendentes do EF Core, se disponíveis.

Estou utilizando um computador da escola que pode não ter SQL Server. Não invente resultados de integração e não tente instalar ferramentas sem minha autorização.
